When translating audio subtitles, it's inconvenient to use a computer, and when changing on a phone, I found no suitable software

I used AI to create one with a feature referenced from Subtitle Edit. Currently, the software's operating logic mainly follows personal usage habits

Currently, the main focus is on improving basic subtitle editing functions, working on new features while optimizing operational logic and fixing bugs

It can quickly align axes using waveform and spectrum diagrams

It is expected that subtitle merging and local deployment of Whisper speech-to-subtitle features will be added in the future
